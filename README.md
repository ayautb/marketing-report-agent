# Marketing Report Agent — Report Runway

Полный комплект приложения находится в [Report-Runway-Windows-v2.zip](./Report-Runway-Windows-v2.zip). Архив включает исходники, исходный PowerPoint-шаблон, шрифты с лицензиями и файлы запуска для Windows и Mac.

## Скачать и запустить

1. Откройте файл ZIP по ссылке выше и нажмите **Download raw file** (значок скачивания).
2. Полностью распакуйте архив. Не запускайте приложение из окна ZIP.
3. На сервере/компьютере нужны **Node.js 24+** и **Python 3.9+**.
4. **Windows:** откройте `Start.bat`. **Mac:** откройте `Start.command`.
5. После сообщения `Report Runway ready` откройте `http://127.0.0.1:4317` на том же компьютере. Окно запуска оставьте открытым.

Для Windows также прочитайте `WINDOWS-START.txt` внутри архива. Нативный запуск Windows-пакета на Windows ещё не проверен.

## Согласованное поведение

- Один общий Executive summary на втором слайде и один общий Next steps на последнем слайде, по главным проектам, выбранным менеджерами.
- Проектные слайды создаются по плану менеджера; автоматические Project Brief и дополнительные KPI-слайды не добавляются. Отдельный редактируемый график создаётся только по явно включённой опции.
- HTML: Executive summary → Main results со всеми проектными слайдами → Next steps, в согласованном тёмном оформлении.
- Месяц на обложке и в HTML отображается как November 2026.

[Полная документация](./docs/README.md) также включена в архив.

Аккаунты и рабочие данные в комплект не входят. При обновлении сохраняйте прежнюю папку `data/` или настроенный `DATA_DIR`.

Для общей работы команды IT размещает одну копию на внутреннем сервере. GitHub хранит файлы проекта и не запускает это серверное приложение. Адрес `127.0.0.1` доступен только на компьютере, где запущен сервер. Финальная отправка, как и ранее, требует подключения утверждённого внутреннего PPTX-renderer; без него доступно только приближённое превью.
